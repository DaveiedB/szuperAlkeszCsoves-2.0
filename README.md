# szuperAlkeszCsöves 2.0

Minecraft resource pack.

> VISSZATÉRTEM!4!4!

## Tartalom

- Egyedi GUI textúrák (HUD, konténerek, menük, sprite-ok)
- Átszerkesztett festmények
- Saját háttér / panoráma
- Módosított `en_us.json` nyelvi fájl és `credits.json`
- Egyedi `pack.png`

## Telepítés

1. Töltsd le a repót (`Code` → `Download ZIP`), vagy klónozd:
   ```
   git clone <repo-url>
   ```
2. A pack mappáját (amiben a `pack.mcmeta` és az `assets` van) másold ide:
   - Windows: `%appdata%\.minecraft\resourcepacks\`
3. Indítsd el a Minecraftot, majd: **Options → Resource Packs**, és told át a bal oldalról a jobbra.

> Ha ZIP-ként töltöd le, a GitHub egy extra mappát tesz köré – a `pack.mcmeta`-nak
> a ZIP gyökerében kell lennie, ezért érdemes a belső mappát külön becsomagolni.
